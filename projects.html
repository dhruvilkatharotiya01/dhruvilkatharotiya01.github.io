Task-aware Grasp Selection and Path Planning for KUKA LBR iiwa Cobots

Master's thesis · Technische Hochschule Ingolstadt · ongoing

A robot should grasp an object in a way that fits what it has to do next. A mug picked up to be poured needs a different grasp than one picked up to be stacked. My thesis studies how to choose grasps with the downstream task in mind and how to plan collision-free motions for the KUKA LBR iiwa 7-DoF collaborative arm.

Local Planning and Evaluation of Evasive Maneuvers for Automated Vehicles

Master's project · THI · 2024 · team of four

A local planner has to make short-term, real-time decisions so an automated vehicle avoids collisions while staying smooth and following traffic rules. We built a Python simulation that decides when the ego vehicle should change lanes and generates a smooth trajectory for doing it.

  • Scenario-based collision detection and lane-change logic using relative positions, velocities and safety distances; validated across 50+ simulated traffic scenarios.
  • Smooth lane-change trajectories using cubic-spline interpolation, with a sigmoid-based variant compared against it. Smoothness was the main challenge.
  • Trained Polynomial Regression and Decision Tree models to predict vehicle positions and explain maneuver decisions, and analysed their sensitivity across 30–130 km/h.

Eco-Driving at Signalized Intersections

Scientific seminar · THI · 2024 · supervised by Anna Lena Schlamp

A literature review of how vehicles can approach traffic lights more efficiently. The idea is to anticipate signal changes, keep speed steady, and avoid unnecessary stops to save fuel and cut emissions.

  • Compared computational approaches: Dynamic Programming, Model Predictive Control, Gaussian Process Regression and Soft Actor-Critic reinforcement learning.
  • Examined integrated evaluation setups that couple traffic, V2X network and driving simulators, and predictive cruise control (Eco-PPCC).
  • Discussed what holds these methods back in the real world, especially without vehicle-to-infrastructure (V2I) communication.
